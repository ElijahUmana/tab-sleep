      How previews work

      When possible, Tab Sleep stores a full-resolution PNG of the last visible page. For never-visible background tabs, it creates a script-free best-effort DOM preview from a detached clone. Both stay local in this Chrome profile. Sleeping replaces the live website with a lightweight extension page; it does not discard that preview, so selecting the tab never reloads the original site.
