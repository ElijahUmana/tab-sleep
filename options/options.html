Tab Sleep

Replace quiet hidden tabs with local frozen previews and reload the live page only when you wake it.

Automatic sleep

Tabs selected in open Chrome windows always stay awake.

Tab Sleep evaluates eligible tabs every 5 seconds. Selecting a frozen tab shows its local frozen visual without loading the website; click anywhere on the visual to wake the live page.

Safety rules

Choose which tabs should remain loaded.

How previews work

When possible, Tab Sleep stores a full-resolution PNG of the last visible page. For never-visible background tabs, it creates a script-free best-effort DOM preview from a detached clone. Both stay local in this Chrome profile. Sleeping replaces the live website with a lightweight extension page; it does not discard that preview, so selecting the tab never reloads the original site.
